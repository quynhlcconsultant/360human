# SỔ TAY KỸ THUẬT - PHÒNG DEV (TECH NOTES)

> Khu vực riêng tư của @TechLead và @Coder_Python. Các phòng ban khác không tự ý ghi đè vào đây.

## Tiêu chuẩn Code (Coding Conventions)
- Mọi script Python phải bao gồm logging (cấp độ INFO trở lên).
- Tên biến đặt theo chuẩn `snake_case`. Hạn chế code thô bạo (spaghetti code).
- Luôn kiểm tra môi trường bằng `virtualenv` trước khi cài thư viện.

## Hướng dẫn kết nối Task OS (Dành cho Coder)
Mật khẩu Server Task OS (Localhost): `admin:antigravity`.
Port mặc định: `8000`. Coder khi viết API phải tuân thủ chuẩn JSON được Sếp phê duyệt.
