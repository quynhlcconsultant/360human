**Tiêu chuẩn cấu trúc thư mục của tôi.**
*Mọi AI Assistant khi tạo nội dung, báo cáo hoặc file mới đều phải tuân thủ quy tắc lưu trữ này. Tuyệt đối không để file rải rác ngoài thư mục gốc.*

---

## 1. Cấu trúc Khung (Root Folders)

| Thư mục         | Mô tả (Chứa cái gì?)                                                |
| --------------- | ------------------------------------------------------------------- |
| `01_MARKETING/` | Nội dung bài viết, hình ảnh thiêt kế, kế hoạch quảng cáo.           |
| `02_SALES/`     | Danh sách khách hàng (CRM), kịch bản chốt sale, báo giá.            |
| `03_PRODUCTS/`  | Hình ảnh sản phẩm, thông tin nhà cung cấp, giá vốn.                 |
| `04_ADMIN/`     | Tài chính, kế toán, văn bản pháp lý, hợp đồng.                      |
| `99_TEMP/`      | File nháp cào trên mạng về, tài liệu dùng 1 lần. Cần dọn mỗi thứ 6. |

<!-- 💡 Cấu trúc trên là ví dụ, hãy tự điều chỉnh lại -->

## 2. Quy Tắc Lưu Trữ Cuối
- **Quy tắc 1 (Ưu tiên dự án):** Nếu file thuộc một Dự án đang chạy, phải lưu vào đúng thư mục con của dự án đó, không lưu vứt vỏng ở ngoài.
- **Quy tắc 2 (File Tạm):** Trợ lý AI khi tự tạo file phân tích trung gian, nếu tôi không yêu cầu lưu trữ dài hạn, hãy lưu tạm vào thư mục `99_TEMP/`.
- **Quy tắc 3 (Tên file):** Không viết dấu tiếng Việt và khoảng trắng trong tên file nếu dùng cho mục đích lập trình / web. (Ví dụ đúng: `bao_cao_quy_1.xlsx`).
