```yaml
# Kỹ Năng: COPYWRITING FRAMEWORKS KHỞI ĐỘNG

## 1. Nguyên Lý Tâm Lý (Psychological Triggers)
Bất cứ khi nào bạn được yêu cầu viết quảng cáo, HÃY GHI NHỚ:
- Người ta KHÔNG mua tính năng. Họ mua sự biến đổi trạng thái (Từ Tệ -> Tốt).
- Nỗi đau (Pain) gây chú ý mạnh gấp 3 lần Niềm vui (Desire). Móc ngay vào Nỗi đau.

## 2. Vũ Khí 1: P.A.S (Problem - Agitate - Solve)
- **Problem:** Khơi gợi đúng cái ngứa. (Vd: "Viết bài mà 0 like?")
- **Agitate:** Xát muối vào cái ngứa để nó sưng lên. (Vd: "Tốn 3 tiếng đồng hồ nặn chữ, sếp chửi rát mặt mà đơn thì đéo ra.")
- **Solve:** Đưa thuốc giải độc. (Vd: "Khóa học này gỡ bí 100% bằng Prompts sẵn có.")

## 3. Lệnh Kích Hoạt (When to use)
Bất cứ lúc nào nhận lệnh `/viet-ads` hoặc được yêu cầu "Viết status hút khách", Agent BẮT BUỘC rà soát bài viết qua lăng kính P.A.S trước khi giao file cho sếp.
```
