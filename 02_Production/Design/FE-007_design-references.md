# Design References — 360Human

> Những website dưới đây được chọn vì phù hợp với vision 360Human:
> warm cream background, editorial typography, premium texture, KHÔNG cold SaaS, KHÔNG cải lương phương Đông.
>
> Mỗi reference kèm: **Học gì** (what to take) + **Bỏ gì** (what to avoid).

---

## 1. Editorial & Typography-First

Websites lấy typography làm trung tâm, whitespace lớn, cảm giác đọc tạp chí cao cấp.

### 1.1 Kinfolk — [kinfolk.com](https://www.kinfolk.com/)

| Aspect | Detail |
|--------|--------|
| **Style** | Editorial magazine chuyển sang web. Serif headings, generous whitespace, gallery-like framing |
| **Học gì** | Cách dùng whitespace như "active space" — không center, mà đặt photo top-right + text bottom-left tạo dynamic tension. Typography hierarchy rõ ràng. Mỗi story = 1 visual moment |
| **Học gì cho 360Human** | Reading cards layout — mỗi topic reading = 1 "editorial spread". Source footnotes nhỏ, muted. Playfair Display headings + Lora body sẽ tạo cảm giác tương tự |
| **Bỏ gì** | Quá nhiều ảnh editorial — 360Human không có photography budget. Layout asymmetry quá mạnh — users cần predictable reading flow |

### 1.2 Aesop — [aesop.com](https://www.aesop.com/)

| Aspect | Detail |
|--------|--------|
| **Style** | Warm earthy palette, distinctive serif font, artistic photography. "Quiet intellectual mood" |
| **Học gì** | Warm color palette (cream + earth tones + muted accents). Card surfaces với subtle warmth. Unconventional layout nhưng vẫn dễ navigate. Typography tạo "sophisticated calm" |
| **Học gì cho 360Human** | Tone "wise elder" — không flashy, không loud. Cream background + warm shadows. Product cards (tương tự reading cards) với typography focus |
| **Bỏ gì** | E-commerce UX patterns không áp dụng. Quá nhiều photography-dependent layouts |

### 1.3 Cereal Magazine — [readcereal.com](https://readcereal.com/)

| Aspect | Detail |
|--------|--------|
| **Style** | Ultra-minimal editorial. Serif typography, muted palette, enormous whitespace |
| **Học gì** | Typography-only landing sections — không cần images để tạo impact. Muted color palette cực kỳ restrained. Line-height generous cho readability |
| **Học gì cho 360Human** | Landing page hero có thể typography-only + wheel illustration. Reading sections dùng generous spacing giống editorial |
| **Bỏ gì** | Quá sparse — 360Human cần warmer, personal hơn. Không có interactivity patterns |

## 2. Warm Cream & Gold Aesthetic

Websites dùng warm backgrounds, gold/amber accents, organic texture — trùng với vision 360Human.

### 2.1 AG1 (Athletic Greens) — [drinkag1.com](https://drinkag1.com/)

| Aspect | Detail |
|--------|--------|
| **Style** | Sophisticated serif + sans-serif pairing. Clean grid. Warm neutrals. Premium health brand |
| **Học gì** | Serif heading + sans-serif body pairing rất clean. Grid-based layout vẫn feel organic. Value props section dùng cards row — tương tự 360Human landing |
| **Học gì cho 360Human** | 3-card value props layout (5 hệ thống / 20.000+ trang / Cá nhân hóa). Typography pairing (Playfair = serif heading, Inter = body) |
| **Bỏ gì** | Product-focused photography. Green accent color |

### 2.2 Flowfest — [flowfest.de](https://flowfest.de/)

| Aspect | Detail |
|--------|--------|
| **Style** | Warm cream background + curved accent stripes (peach, coral, mustard, honey). Rounded display font + friendly sans-serif body |
| **Học gì** | Warm cream (#F7F3ED tương tự) background thực tế trên web. Multiple warm accent colors harmonized. Curved/organic shapes trên cream background |
| **Học gì cho 360Human** | Warm background color reference thực tế. Cách layer warm colors mà không bị "muddy". Section dividers dùng organic curves thay vì straight lines |
| **Bỏ gì** | Event-focused UX. Quá playful — 360Human cần premium/wise hơn |

### 2.3 Markaware — [markaware.jp](https://markaware.jp/)

| Aspect | Detail |
|--------|--------|
| **Style** | Japanese minimalism. Cream text boxes + dark imagery. Extreme negative space. Left-aligned text |
| **Học gì** | Cream (#F5F0E8 range) dùng cho text containers trên dark imagery = readable + warm. Minimal text — mỗi section chỉ vài từ. Japanese design sensibility = restraint |
| **Học gì cho 360Human** | Reading card surfaces — cream/warm-white cards trên cream background tạo subtle depth. Typography spacing reference |
| **Bỏ gì** | Quá minimal cho content-heavy app. Dark imagery không phù hợp |

## 3. Competitor & Astrology Apps

Apps cùng ngành — học patterns tốt, tránh mistakes.

### 3.1 Co-Star — [costarastrology.com](https://www.costarastrology.com/)

| Aspect | Detail |
|--------|--------|
| **Style** | B&W minimalist. Dark background. Strong typography. AI-powered daily notifications |
| **Học gì** | Information hierarchy — complex astro data → simple daily insight. One action per screen. Push notification strategy (1 per day = healthy habit). Underlined links = clear clickability |
| **Học gì cho 360Human** | Daily ritual UX pattern (Sprint 2). Accordion-style data reveal. Chart ↔ text linked interaction (S5 Interactive mode) |
| **Bỏ gì** | "Tối quá, text heavy, no highlight, boring, cold B&W, emotional distance" (from Figma research). Centered text alignment = poor readability. No warmth |

### 3.2 The Pattern — [thepattern.com](https://www.thepattern.com/)

| Aspect | Detail |
|--------|--------|
| **Style** | Dark with colorful accents. Personality-driven. Multiple chart types |
| **Học gì** | "Components đẹp, font chữ okiela" (from Figma research). Nhiều component types cho different data |
| **Học gì cho 360Human** | Component variety — different cards for different data types. Chart visualization approaches |
| **Bỏ gì** | "Thiếu system khi đọc thông tin, màu thiếu sự hòa hợp" (from Figma research). Messy color system |

### 3.3 Horos — (App Store)

| Aspect | Detail |
|--------|--------|
| **Style** | Unique UI, fresh colors, phù hợp giới trẻ |
| **Học gì** | "UI độc nhất, tạo màu mới mẻ, nhiều components độc nhất" (from Figma research) |
| **Học gì cho 360Human** | Fresh, non-generic approach. Custom components thay vì dùng stock patterns |
| **Bỏ gì** | "Nhiều thông tin không cần thiết với users, text rất nhiều" (from Figma research). Information overload |

## 4. SaaS & Product UX Patterns

Websites có UX patterns tốt cho dashboard, pricing, onboarding — không phải aesthetic mà là functional reference.

### 4.1 Linear — [linear.app](https://linear.app/)

| Aspect | Detail |
|--------|--------|
| **Style** | Dark background, Inter font, gradient purple. "Professional to engineers" |
| **Học gì** | "Typography hierarchy, dark mode warmth, motion restraint" (from Figma research). Animation = purposeful, không decoration. Page transitions smooth. Subtle micro-interactions |
| **Học gì cho 360Human** | Motion design — 200ms fade transitions, 150ms hover lifts, 100ms button presses. Loading states. Keyboard navigation patterns. If dark mode later: Linear's warm-dark = reference |
| **Bỏ gì** | Dark theme (360Human = cream/light). Developer-focused aesthetic. Gradient effects |

### 4.2 Notion — [notion.so](https://www.notion.so/)

| Aspect | Detail |
|--------|--------|
| **Style** | Clean, warm-neutral, serif/sans-serif toggle, block-based content |
| **Học gì** | "Warm cream backgrounds, clean typography, restraint" (from Figma research). Content blocks = scannable. Toggle between views. Sidebar navigation |
| **Học gì cho 360Human** | Sidebar navigation pattern (AppLayout). Content blocks → reading cards. Accordion/toggle UI. Warm neutral palette as daily-use interface (not just landing page) |
| **Bỏ gì** | Block editor UX — irrelevant. Flat/gray aesthetic cho content areas |

### 4.3 Stripe — [stripe.com](https://stripe.com/)

| Aspect | Detail |
|--------|--------|
| **Style** | Gradient accents, clean grid, excellent pricing page, progressive disclosure |
| **Học gì** | Pricing page layout — 2-3 tier cards, feature comparison table, FAQ below. Progressive disclosure — show simple first, details on demand. Checkout flow patterns |
| **Học gì cho 360Human** | S7 Pricing page structure. Checkout flow (VietQR section). Feature comparison table formatting. Tier card hover/highlight states |
| **Bỏ gì** | Gradient heavy. Developer documentation style. Cold blue palette |

## 6. Typography Trends 2026

Xu hướng font và typography mới nhất.

### Key Trends

| Trend | Description | 360Human Application |
|-------|-------------|---------------------|
| **Serif revival** | Serif fonts returning for warmth, authority, editorial feel | Playfair Display headings, Lora reading body — đã áp dụng |
| **Warm typography** | "Cute and cozy" fonts, humanist sans-serifs with rounded details | Inter (humanist sans) cho UI — đã áp dụng |
| **Generous spacing** | Line-height 1.6-1.8, letter-spacing 0.01-0.02em, max 68 chars/line | Vietnamese rules: LH 1.7+ body, 1.8 reading — đã áp dụng |
| **Font pairing** | Serif display + sans-serif body = modern editorial | Playfair + Inter + Lora + JetBrains Mono — đã áp dụng |
| **Variable fonts** | Single font file, multiple weights = better performance | Consider switching to variable font versions for production |

## Anti-References — What 360Human AVOIDS

| Pattern | Why avoid | Seen in |
|---------|----------|---------|
| Pure B&W, no warmth | "Cold, boring, emotional distance" | Co-Star |
| Text walls, info overload | "Nhiều thông tin không cần thiết" | Horos, The Pattern |
| Neon on dark | Anxiety-inducing, not calming | Many astrology apps |

## Browsing Checklist

Khi duyệt các references, focus vào:

- [ ] Cream background hex — so sánh với `#F7F3ED` của mình
- [ ] Card elevation — shadow depth, border style
- [ ] Typography sizing — heading vs body ratio
- [ ] Spacing between sections — có đủ "breathe" không
- [ ] CTA button style — shape, color, hover state
- [ ] Mobile responsive — accordion, stack, hide patterns
- [ ] Loading/skeleton states — shimmer style, duration
- [ ] Pricing page — tier card layout, feature table format
